
# Cookie Hugging Time

## Intro:
We all know how much we love cookie, this group and the rest of BrainerX Constantine students, but it can be overwhelming for `Cookie` and her social battery to be hugged many times at once.

## Instructions
- Create a scheduler for hugging `Cookie`
- Fetch the hugger's name, date and time they want to hug Cookie in
- Save the new hugger's data (in an array for now)

## Styling
You are provided with the necessary HTML and minimal `CSS`, so feel free to expand with the CSS

2 color palettes were suggested in the `style.css` file (look at the end of the file), yet you can use any other color pallets

- Use CSS Variables
- Made sure to make the page responsive by adding `@media` rules
- Feel free to add anything else
- Add any pics you like for `Cookie` if you have none, ask for them (Be careful with the dimentions and responsive design)
